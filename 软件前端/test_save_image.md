# 测试保存图片功能说明

## 环境说明
- 前端服务器：http://localhost:8000/html/shouye.html
- 后端服务器：http://localhost:5000

## 测试步骤

1. **打开首页**
   - 访问：http://localhost:8000/html/shouye.html

2. **点击热门推荐项**
   - 在热门推荐模块中，点击任意一个动漫或特摄剧的卡片
   - 这将打开一个包含资源详情和图片预览的弹窗

3. **上传图片**
   - 在弹窗中，点击"选择图片上传"按钮
   - 从本地选择一张图片文件（支持JPG、PNG等图片格式）
   - 等待图片加载和压缩完成（弹窗中会显示预览）

4. **保存图片**
   - 点击"保存图片"按钮
   - 应该会看到"图片已保存成功！"的提示

5. **验证保存结果**
   - 关闭弹窗
   - 再次点击同一个热门推荐项
   - 确认图片已经被正确保存和显示

6. **验证轮播图更新**
   - 刷新页面
   - 如果该资源出现在轮播图中，确认图片已经正确显示在轮播图中

## 功能说明

- 图片会被压缩后保存到浏览器的localStorage中
- 支持同时通过资源ID和标题查找保存的图片
- 保存后会立即更新热门推荐和轮播图中的图片
- 当存储空间不足时，会自动清理旧的图片数据

## 注意事项

- 请确保前端和后端服务器都在正常运行
- 图片大小建议不要超过2MB，以避免存储空间不足
- 如果保存失败，请查看浏览器的开发者工具控制台以获取详细错误信息
